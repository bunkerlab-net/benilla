# Genuine resident dry player environment replies

ResidentPlayerEnvironmentProvider retains the actual borrowed prepared source
composition and an environment identity derived from that composition. Binding
requires the existing source-owned player height and environment policy, exact
Profile/session/player selection and a complete catalog whose whole WDBC digest
matches the genuine selected terrain receipt. No caller inventory or policy
identifier is substituted for the derived identity.

Resolution validates the exact PlayerEnvironment query transcript through the
existing session/policy checks: owner, player, height, sequence/ticket, pose,
required mask15 and snapshot binding. It then performs the actual source-ordered
point absence query against loaded terrain and resident collision, and creates
PlayerEnvironmentFacts with the unchanged query, NO_WATER and no liquid data.
Absence precedes height-dependent classification; the source-owned height remains
in the exact query transcript. Wet products and missing required geometry fail
rather than synthesizing dry facts.

The runtime relocation/countdown reducer owns consumption and cache updates.
A provider may legitimately re-answer an exact immutable historical query;
policy equality does not certify a current runtime frame. Stale facts must be
rejected against the reducer's current query. This provider does not refresh a
Chase target at its current position: the Chase water gate continues reading the
runtime cache, including its intentionally older cached query position.

Cancellation/deadline checks surround validation and source queries, with a
final source freshness check before returning Facts. These are sequential
observations, not an atomic filesystem lease. Existing bounded synchronous query
and source-read sections retain their documented responsiveness limitations.

The complete wet-product environment provider is unchanged. This component does
not acquire catalogs, initialize model/starter witnesses, install a normal game
session, construct Route/cache/commit evidence or admit a populated world. The
surrounding authored model and movement test authority remains explicitly scoped;
only the dry environment facts are now obtained from actual consumed products.
