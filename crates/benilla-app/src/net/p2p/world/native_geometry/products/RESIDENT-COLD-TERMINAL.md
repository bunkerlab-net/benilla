# Conditional resident cold same-polygon observations

This private composition connects a genuine generated source1024 query, its live
owner constructor and the resident point filter to the existing native cold
same-polygon implementation. It returns a conditional query result. It does not
establish that the Chase caller selected this path, provide a movement Route,
export native cache storage, or commit a world change.

## Order and supported domain

The constructor must already have its genuine source filter observation. For an
exact first live ChaseInitial/ChaseReplan dispatch with no prior cache, matching
launch origin and the source 74-point limit, the operation:

1. Revalidates that constructor observation and current consumed sources
2. Uses the same retained query for source destination/start checks and selection
3. Requires the exact owner-ignore receipt and rejects ignore-pathfinding
4. Performs source HaveTile(start), then HaveTile(destination); missing coverage
   stops before any calculate-time liquid observation
5. Obtains fresh mask 15 then mask 10 point observations and preserves the source
   filter bits; constructor observations cannot substitute for this update
6. Runs the existing bounded cold same-polygon implementation on that selection
7. Checks allocation, endpoints, NORMAL/active-one result and initial zero storage,
   then checks current context, deadline and consumed source freshness again

Normalization is explicitly false/false; native lookup and terminal budgets retain
the existing bounds. Different polygons, missing geometry, wet data, unsupported
profiles or initialization, stale identity and exhausted budgets remain errors.
Wander, Home, backpedal and retained-cache continuation are not this entry point.

The existing cmangos-buildpolypath-zero-distance-v1 compatibility repair stays
attached to the private terminal and checked diagnostic observations. Original cold
distance locals are undefined; this is not a claim of unmodified cold-source parity.
Ground habitat 1 has genuine initialization coverage. Habitat 3 remains the separate
initialization limitation documented in RESIDENT-POINT-FILTER.md.

## Lifetime and authority

A move-only private dependency retains owner-ignore and tile evidence, fresh point
observations and the native terminal. The terminal never escapes. Read access
rechecks provider allocation, exact live request, expiry and consumed-source
freshness, and returns copied numeric observations only. Those observations cannot
be converted into Facts, Route or PathFinderCache. Failed computations publish no
terminal and do not commit a path cache; bounded native query scratch may change,
as in the existing implementation, so a valid same-dispatch retry is allowed.

Source freshness remains sequential observation, not an atomic filesystem lease.
Cancellation/deadlines are checked around bounded native calls and source reads;
there is no mid-call preemption. New movement/dispatch/source state requires new
observations. Source caller distance/vertical/LOS/owner-water/target-water gates,
cached player environment, near-point/clearance/support and atomic route commit
remain prerequisites for actual Chase movement. In particular, owner-point NO_WATER
does not prove a target or segment is dry.
