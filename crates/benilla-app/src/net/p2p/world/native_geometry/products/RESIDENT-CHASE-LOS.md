# Resident Chase numeric/LOS prefix

This optional composition accepts an already-valid initialized Profile and its
exact live constructor/filter dependency. It reuses the existing gate_model checks
for source-selected creature model/combat reach, width, owner collision height,
per-generation identity and starter-owned player height. Neither Session body
scalars nor caller-supplied heights can replace those witnesses.

The fixed enabled-LOS scope follows source distance, then vertical predicates,
then VMap ray. Numeric rejection returns a rejected prefix without a ray. Endpoints
are owner XYZ plus owned creature height to the calculated goal plus owned player
height, not current target XYZ. The source ignore_m2 flag is always false. A hit is
Blocked; a miss is ClearPrefix; required unloaded geometry remains an error.

The private dependency binds provider allocation, complete live request, validated
model witnesses, target player and expiry capped by constructor evidence lifetime.
Read access checks exact live dispatch, context, model identity and consumed source
freshness before returning copied decision/ray diagnostics. The capture remains a
historical immutable geometry snapshot; sequential source rechecks are not an
atomic filesystem lease. Synchronous source reads and bounded native calls are not
preemptible midway through a call.

## Initialization boundary

No extractor, catalog capture or importer is added here. Tests use the existing
catalog loaders and authored source initializer inputs to obtain their actual typed
model and starter witnesses. Existing client-loader patch policy is not treated as
terrain/collision source provenance. Real-install server model selection, retained
player starter identity and a source-bound fresh model/catalog capture remain
unconnected. This prefix is usable only when its caller already possesses a valid
initialized profile; it does not construct one from client assets alone.

## Remaining source caller stages

Source constructor/createFilter precedes this prefix. Fresh owner IsInWater,
runtime-owned cached target water and calculate follow it. ClearPrefix does not
claim those steps ran or source selected straight calculation. A new point query
cannot substitute for the target player's timed cached environment. NearPoint,
clearance/support, concrete corridor certification and atomic route commit remain
separate. This type cannot become a Route, Facts, cache publication or live world
admission, and it does not expose the private cold terminal from the next stage.
