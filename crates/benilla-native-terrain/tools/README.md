# Dry terrain source oracle

The fixtures are entirely authored test data, never extracted game assets. Each
`.map` is the byte output of original CMaNGOS Classic revision
`8ec338a1704e7dcb1c0213eb7ed58f9231ade40f`, `ConvertADT`, with `-f 0` and the
original minimum-height defaults. The companion `.adt`, DBC and WDT inputs are
generated by `generate_terrain_writer_fixture.py`; no Rust writer is imported.

```sh
python3 crates/benilla-native-terrain/tools/generate_terrain_writer_fixture.py \
  --core /path/to/pinned/cmangos --check-fixtures
python3 -m unittest discover -s crates/benilla-native-terrain/tools -p 'test_*.py'
```

`--write-fixtures` intentionally replaces fixtures after all source hashes and
the audited compiler profile pass. The check compares every input, every output
byte and the manifest. Compiler absence or drift is an error, never a skip.
The profile is g++ 14.2.0, `x86_64-linux-gnu`, IEEE little-endian floats,
round-to-nearest, no fast math or contraction. The manifest records exact source
file hashes, selected System.cpp intervals, compiler flags, and product hashes.

## Source boundary

The generator compiles the unchanged original `DBCFile`, `FileLoader`, ADT
structures/getters/validation, DBC-loading methods, and complete `ConvertADT`
body. It builds a small test executable, not `ad` or another external extractor.
The only external leaf substitution is `fixture_mpq.h`: `MPQFile` reads the
generated local fixture bytes instead of resolving MPQs. Original source
headers, implementation files, and license notices are copied unchanged into a
temporary compilation directory. The System.cpp notice is retained before its
unmodified selected intervals. CMaNGOS grants are GPL-2.0-or-later; this combined
harness is GPL-3.0-or-later.

Undefined-behavior sanitization is enabled except alignment: the original writer
casts FourCC string literals to `uint32*`. Strict aliasing is disabled for this
same source idiom. This exception is recorded, not a claim of portable source
behavior. The original source parser uses unchecked pointer arithmetic; the
fixture harness is only run on these known authored inputs. It is not a safe
general-purpose ADT/DBC parser and must never consume game or untrusted assets.

## Coverage and limits

The cases cover flat versus float output, tiny nonzero ranges under `-f 0`,
V9/V8 deinterleaving, shared-seam overwrite order, mixed and complete -500 clamp,
the original 20000 minimum-scan seed, full/uniform/fallback area storage,
duplicate-row last-wins, uint16 narrowing, ID-zero fallback, and all hole bits in
both flat and nonflat output. Missing MCVT uses direct base assignment, including
preservation of negative-zero bits. Reversed MCNK coordinate metadata
demonstrates that placement follows the MCIN slot, not the coordinate fields.

Every listed fixture is within the bounded Rust profile. No negative parser
input is executed through upstream's unsafe parser. Malformed-input rejection
belongs to the Rust tests.

These vectors establish byte parity for dry terrain only. They do not establish
MPQ patch-winner parity, install coverage, wet terrain, live source leases,
VMap/MMap generation, world-content compilation, or gameplay admission. The WDT
is an authored selection fixture for Rust integration; `ConvertADT` does not
read it. Selected map 1, output grid `(31, 32)`, uses ADT filename
`AuthoredOracle_32_31.adt` and output `0013132.map`.
