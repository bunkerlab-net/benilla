# Classic terrain source oracle

The fixtures are entirely authored test data, never extracted game assets. Each
`.map` is the byte output of original CMaNGOS Classic revision
`8ec338a1704e7dcb1c0213eb7ed58f9231ade40f`, `ConvertADT`, with `-f 0` and the
original minimum-height defaults. The companion `.adt.test-fixture`,
`.dbc.test-fixture` and `.wdt.test-fixture` inputs are generated by
`generate_terrain_writer_fixture.py`; no Rust writer is imported. The authored
input suffix keeps these fixtures in corresponding-source packages. The source
oracle reads temporary unsuffixed names before the generator renames persisted
inputs; real MPQ member names and `.map` output names remain unchanged.

```sh
python3 crates/benilla-native-terrain/tools/generate_terrain_writer_fixture.py \
  --core /path/to/pinned/cmangos --check-fixtures
python3 -m unittest discover -s crates/benilla-native-terrain/tools -p 'test_*.py'
```

`--write-fixtures` intentionally replaces fixtures after all source hashes and
the audited compiler profile pass. The check compares every input, every output
byte and the manifest. Compiler absence or drift is an error, never a skip.
The profile is g++ 14.2.0, `x86_64-linux-gnu`, IEEE little-endian floats,
round-to-nearest, no fast math or contraction. The manifest records exact source
file hashes, selected System.cpp intervals, compiler flags, and product hashes.

## Source boundary

The generator compiles the unchanged original `DBCFile`, `FileLoader`, ADT
structures/getters/validation, DBC-loading methods, and complete `ConvertADT`
body. It builds a small test executable, not `ad` or another external extractor.
The only external leaf substitution is `fixture_mpq.h`: `MPQFile` reads the
generated local fixture bytes instead of resolving MPQs. Original source
headers, implementation files, and license notices are copied unchanged into a
temporary compilation directory. The System.cpp notice is retained before its
unmodified selected intervals. CMaNGOS grants are GPL-2.0-or-later; this combined
harness is GPL-3.0-or-later.

Undefined-behavior sanitization is enabled except alignment: the original writer
casts FourCC string literals to `uint32*`. Strict aliasing is disabled for this
same source idiom. This exception is recorded, not a claim of portable source
behavior. The original source parser uses unchecked pointer arithmetic; the
fixture harness is only run on these known authored inputs. It is not a safe
general-purpose ADT/DBC parser and must never consume game or untrusted assets.

## Coverage and limits

The cases cover flat versus float output, tiny nonzero ranges under `-f 0`,
V9/V8 deinterleaving, shared-seam overwrite order, mixed and complete -500 clamp,
the original 20000 minimum-scan seed, full/uniform/fallback area storage,
duplicate-row last-wins, uint16 narrowing, ID-zero fallback, and all hole bits in
both flat and nonflat output. Missing MCVT uses direct base assignment, including
preservation of negative-zero bits. Reversed MCNK coordinate metadata
demonstrates that placement follows the MCIN slot, not the coordinate fields.

The Classic MCLQ cases cover absent records despite MCNK type bits; empty
records and MCNK sizes 0 through 8; full records with either zero or 804 inner
size; water, ocean and magma; independent type-bit accumulation and last-set
entry precedence; whole-byte `0x0f` hiding versus visible/deep `0x8f`; deep-only
and untyped-visible records; uniform versus full type arrays; flat versus float
heights; non-square cropped bounds; hidden samples assigned -500; shared-seam
last-wins ownership; and fully written outer row/column 128. A sparse flat -625
case proves liquid heights are not terrain-clamped and that absent edge heights
are irrelevant when `MAP_LIQUID_NO_HEIGHT` suppresses serialization.

`DRY_CASES` retains the original 13 dry vectors. `LIQUID_CASES` adds 15 admitted
Classic MCLQ vectors. The generator verifies all 28 admitted outputs are
byte-identical after each of two distinct, valid preceding tiles, and applies
the same check to both `HISTORY_SEED_CASES`. Every emitted
header/type/height branch is covered. No negative parser input is executed
through upstream's unsafe parser. Malformed-input rejection belongs to Rust
tests, including wholly hidden typed liquid whose source bounds would be unsafe.

### Source history is part of the oracle

Original `ConvertADT` clears liquid visibility, entries and flags, but does not
clear its global `liquid_height`. Its masking scan visits coordinates 0 through
127, while the serialized height rectangle may include row or column 128.
An unwritten outer-edge sample can therefore retain a previous tile's height.
The fixture driver never replaces, clears or patches those source globals.

The two `ORACLE_ONLY_CASES`, `liquid_stale_edge_a` and `liquid_stale_edge_b`,
have identical ADT bytes. They run in separate fresh processes with explicit
same-process source histories: water at 23.5 then case A; deep ocean at -17.25
then case B. Their resulting maps differ at exactly 199 unwritten outer-edge
height samples. The manifest records each predecessor and marks both cases
`rust_supported: false`, with a rejection reason. Rust must reject these shapes
rather than choose an initial height when no proven history context is supplied.
These original input/output bytes and manifest case entries remain unchanged;
their support field records the standalone, history-free writer contract.
The history-aware path may resolve them from the explicit preceding writers.
Conversely, a fully written outer edge is admitted without history, as
is the sparse flat case whose edge samples are never emitted.

### Exact 61-sample dependency shape

Eight `HISTORY_CASES` share identical authored ADT bytes with rectangle
`x=47, y=0, width=79, height=129`. Five active MCLQ cells give visible points
`(47,0)`, `(124,0)` and `(47,127)`. The last-row cells at columns 5, 6 and 7
write the emitted boundary from x=47 through x=64, including conflicting seams;
columns 6 and 7 are entirely hidden and untyped. Exactly 61 serialized values
are unwritten by the selected ADT: `(65,128)` through `(125,128)`.
This recreates only the reported diagnostic shape, not an actual asset or its
cell count. No input bytes come from a game install.

Every selected case runs in its own fresh executable process with its complete
listed source history, in forward order:

- `liquid_history61_initial`: no predecessor, preserving the source's static +0
- `liquid_history61_positive`: `liquid_water_flat`, preserving +23.5
- `liquid_history61_negative`: water then `liquid_ocean_flat`, taking -17.25
- `liquid_history61_dry`: ocean then `flat`, retaining -17.25 through no writes
- `liquid_history61_untyped`: ocean then `liquid_untyped`, taking +23.5 from a
  predecessor that emits no MLIQ
- `liquid_history61_hidden`: water then `liquid_history_hidden_seed`, taking
  -42.75 from fully hidden, untyped records that emit no MLIQ
- `liquid_history61_seams`: `liquid_seams`, taking the last row-major writer at
  each shared boundary seam
- `liquid_history61_partial`: ocean then `liquid_history_partial_seed`, taking
  exact negative-zero bits at x=72..80 and -71.125 at x=88..96, retaining -17.25
  elsewhere

Both new seed fixtures are safe complete `ConvertADT` inputs: their MCNK type
bits are zero and every MCLQ visibility byte is `0x0f`, so the unsafe wholly
hidden *typed* packing branch is never reached. They produce the same dry map as
`flat` while still mutating the global raw heights. The sparse seed demonstrates
that a later tile can resolve only some values; each remaining sample retains
its own latest earlier writer. Predecessor output heights are not replayed.

Tests inspect the generated ADT bytes independently of the authoring helper,
check the rectangle and exact missing set, preserve signed-zero bits, and prove
that every byte outside these 61 float samples is identical across histories.
The manifest marks these eight cases `rust_supported: true` together with
`requires_proven_history: true`; this is the context-bound writer contract,
never permission to assume zero. Production may use +0 only after proving the
entire preceding source traversal is exhausted. These executable histories
establish direct-write behavior, not Map.dbc/WDT traversal order, absent-member
proof, archive stability, or production history-budget behavior.

These vectors establish byte parity only for the described bounded dry and
Classic MCLQ profiles. They do not establish MPQ patch-winner parity, install
coverage, MH2O terrain, live source leases, VMap/MMap generation, world-content
compilation, or gameplay admission. The WDT
is an authored selection fixture for Rust integration; `ConvertADT` does not
read it. Selected map 1, output grid `(31, 32)`, uses ADT filename
`AuthoredOracle_32_31.adt` and output `0013132.map`.
